Where is my data stored?

        
Nowhere. The link carries its own encrypted destination. There is no database to hack,
          subpoena, or sell.

        
Can someone without the password read it?

        
No. AES-256 encryption, post-quantum resistant. The weak point is always a weak
          password — which is why there's a suggested-passphrase button.

        
Does the server ever see my password?

        
Never. Unlocking happens entirely in your browser.

        
Where can links leak?

        
Browser history and cloud sync store full URLs. Treat auto-open links like passwords.

        
Can a link be taken back?

        
A stateless link can't be revoked — only its password can stop being shared. That's
          the trade for storing nothing.
